# Equipment Database Operations Console

##  Project Overview

The **Equipment Database Operations Console** is a Java desktop application developed to manage laboratory equipment records using a graphical user interface and a relational database.

The project demonstrates my practical skills in **Java, Java Swing, JDBC, SQL, and Apache Derby**.

##  Features

* 🔐 Connect to an Apache Derby database
* ➕ Add new equipment records
* 📋 View all equipment records
* 🔎 Search equipment by name
* 🏢 Filter equipment by department
* 📊 View database statistics through a dashboard
* 💰 Calculate total equipment expenditure
* 📉 Find the cheapest equipment
* 📈 Find the most expensive equipment
* 🔄 Update Multimedia equipment records
* 🗑️ Delete damaged equipment that is not in use
* 🧹 Clear displayed search results

The application connects to an Apache Derby database called:

text

The main table used by the application is:

text

It stores information such as:

* Equipment ID
* Equipment name
* Department
* Purchase date
* Condition
* In-use status
